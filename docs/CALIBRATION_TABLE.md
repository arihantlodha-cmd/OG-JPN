## Demographics

Pulled live from the UN World Population Prospects via `ogcore.demographics`, country code 392, with `income_percentiles` passed so the arrays are J-wide. Fertility, mortality and population are UN series; immigration is solved as the residual that reconciles consecutive UN distributions.

## Earnings

The `e` matrix is built in `ogjpn/income.py` by the family's two-part method: an NTA age-shape adjustment (Japan 2004 against the US 2003) followed by a single-scalar tilt to Japan's Gini of 32.3.

## Deliberately NOT calibrated

In a country port the parameters you did not set matter as much as those you did, because anything unset silently keeps OG-Core's United States value. These are left, with reasons:

| Parameter | State | Why |
|---|---|---|
| `chi_n` | OG-USA's profile | labour input per working-age person is within 1% of the US (1,278 vs 1,288 hours), so borrowing is harmless |
| `lambdas` | family-standard percentiles | byte-identical across every country port; only the earnings tilt differs |
| `sigma, frisch` | OG-Core literature values | deep preference parameters; no Japanese observable identifies them |
| `fert/mort/infmort_gradient` | left unset | Demographic-Gradients excludes high-income countries and forbids extrapolating its fallback |
| `initial_wealth_ratio` | undiagnosed | affects the TRANSITION only; flagged as the main open risk |
| `epsilon` | 1.0 (Cobb-Douglas) | no Japanese estimate applied |
